# Product-Expiry-Management-System
A Python-based desktop application using PyQt5 that helps track and manage product expiry dates. It allows users to add, search, and delete products while storing data in SQLite. The system also provides alerts for products nearing expiry, helping reduce waste and improve inventory management.

This project does not rely on any pre-existing dataset. Instead, it uses a dynamically created SQLite database where users input and manage product details in real time.
